## 2026-10-28 · feature/plan-orders

오늘 한 작업
* 계획 명령: 웨이포인트에 대기 조건(신호 1~3 / H시 / ○소대 접촉 시 / ○소대 도착 시, 하나라도 충족되면 출발)과 해제 시 사격 방침을 붙임
* 신호 발신(진영 전체 방송, 각 소대가 기다리는 번호로 구분), H시 지정·변경 — 둘 다 명령처럼 통신을 탐
* ○소대 접촉/도착: 본부가 그 보고를 받는 순간 그 사건을 기다리는 소대에 자동 통지 → 통지가 도착하면 출발. 보고가 늦으면 출발도 늦음
* 자기 소대 접촉 = "내가 적을 발견하면"(통신 불필요) → 매복: 사격 금지로 대기, 접촉 시 자유 사격으로 해제
* 그리드 단축키: Q W E R(신속·일반·은밀·정지) / A S D F(엄폐 후 응사·돌파·후퇴·경계) / Z X C V(신호·H시·접촉 시·도착 시), F1~F3 신호 발신, [ ] H시 조정(손 떼고 1.5초 뒤 하달)
* 화면: 대기 지점 마름모 + 조건 글자, 소대 상태 "대기: 신호 1", 명령 패널에 대기 조건·해제 시 사격·신호·H시 줄, 범례
* 테스트 13개 추가 (총 72개)

문제 / 결정 사항
* 작전의 동시성은 반사신경이 아니라 계획으로 — 실제 군대가 H시·암호 신호를 쓰는 이유와 같음. 신호는 유연하지만 통신에 약하고, H시는 튼튼하지만 상황을 못 봄 → 둘을 같이 걸 수 있게
* 네 가지를 따로 만들지 않고 "웨이포인트의 대기 조건" 하나로 묶음(망치와 모루 외에 포위·성동격서·침투·교대 엄호 후퇴·매복으로 검증)
* 두절 중 대기: 120초 뒤 기존 규칙대로 자체 판단(고수). 그래도 H시·자기 소대 접촉 조건은 살아 있음. 두절 중 보낸 신호는 보류됐다가 회복되면 늦게 도착(늦은 신호에 혼자 출발할 수 있음 — 현실적, 배울 거리)
* H시 변경도 통신을 탐: 두절된 소대는 예전 H시로 움직임
* 대기 조건·해제 시 사격은 웨이포인트 하나에만(찍으면 초기화), 이동 방식·접촉 시 행동은 계속 유지
* 대기를 푼 신호·통지는 소모. 새 명령(새 경로·경계·정지)을 받으면 대기와 이전 신호·통지를 잊음
* 접촉 통지는 같은 소대 기준 60초에 한 번(교전 중 보고마다 쏟아지지 않게)
* 정지 키 H → R(그리드 1행). 씬에 저장된 값도 R로 바꿈
* 원형 메뉴는 보류 — 조작계를 둘 만들면 둘 다 어설퍼짐. 엔진 명령은 조작과 분리돼 있어 나중에 얹을 수 있음
* 적 AI가 계획 명령을 쓰는 건 적 지휘관 2단계(의외성·사전 징후)와 함께 — 적이 대기 지점에 모이는 것 자체가 징후가 됨
* 대기 조건이 없는 판은 이전과 완전히 같음(테스트·방어 시나리오 공격 판 80개 사건 로그 해시 일치)

## 2026-10-28 · feature/enemy-commander-ai

오늘 한 작업
* 적 지휘관 AI 1단계(방어하는 적): 결정 지점에서만 판단 → 후보(고수·증원·후퇴·역습 × 진지) 점수 → 가장 높은 후보 실행 → 기동 추적(도착하면 경계로 마무리)
* 점수 = 신중 점수·공격 점수를 그 순간의 공격성으로 가중합 + 무작위(±8) + 유지 보너스(+15). 상황 보정: 병력 우세/열세(싸울 수 있는 아군 소대 수 vs 최근 본 접촉 수) ±0.10, 아군 피해 누적(전투 가능 70% 미만) −0.15
* 결정 지점: 새 접촉, 진지 위협 반경 안 접촉 증가, 소대 피해(70%·50% 아래), 붕괴 보고, 기동 완료, 60초 정기 점검. 판단 소요 10초
* 성향(CommanderPersonality: 공격성 0~1)과 실력(CommanderSkill: 무작위 폭·판단 소요·점검 간격·유지 보너스 = 난이도 손잡이)을 따로 둠
* 방어 계획 데이터(DefensePlan): 진지(담당 소대·위협 반경·경계 방향·후퇴 위치) + 예비대
* 방어 시나리오(DefenseScenario): 같은 1km 지도, 블루 1·2·3소대 + 본부 / 레드 본부 + 1진지·2진지 + 예비대(3소대). 신중 65 / 공격 35. 컨트롤러 Inspector에서 시나리오 선택(기본은 기존 테스트 시나리오)
* 판단 로그: "지휘관 판단(새 접촉): 증원 → 1진지 [후보별 점수] (공격성 0.45)" — 적 로그라 실제 전황(T)일 때만 보임
* 지역 확보 판정 수정: 사기 붕괴한 적도 구역 안에 있으면 확보가 안 됨(전투 불능만 제외). 지역 방어도 같은 판정을 씀
* 테스트 9개 추가 (총 59개)

문제 / 결정 사항
* 페이싱 논의: 20배속이어야 이동이 답답하지 않지만 그러면 교전(게임 7~8분)이 실제 20초 남짓. 맵 축소(관측 800m보다 작으면 안개·역사면·무전 음영이 무의미)·이동 속도 상향(고증)은 하지 않음. 작전의 동시성은 계획 명령으로, 배속 장치(교전 중 상한·결정 순간 일시정지)는 보조. 1번 맵(순수 보병)의 페이싱 판단을 장비 맵에 그대로 옮기지 않음
* 반칙 금지: 적 지휘관은 레드 상황판의 접촉과 아군 보고만 씀(실시간 보고 중이면 현재, 아니면 마지막 보고 — 플레이어 화면과 같은 규칙). 명령도 플레이어와 같은 명령이라 통신 지연을 똑같이 탐. 본부가 없거나 전멸하면 아무것도 안 함
* 지휘관 난수는 따로 씀 → 지휘관이 없는 판은 이전과 완전히 같음(테스트 시나리오 40판 사건 로그 해시 일치로 확인)
* 진지·후퇴 위치는 시나리오가 지정. AI가 지형을 보고 고르는 건 나중(난이도 "내다보기")
* 적 규모는 모름 — 병력비는 소대 수 vs 접촉 수로만 판단(틀릴 수 있음)
* 예비대는 한 번만 투입. 포기한 진지로는 다시 안 돌아감
* 실행할 수 없거나 말이 안 되는 후보(예비대 없는 증원, 열세인데 역습, 전투 불능 진지의 고수)는 점수 매기기 전에 뺌
* 정기 점검에서 판단이 그대로면 로그에 안 남김(판단 기록에는 남음) — 같은 줄이 1분마다 쌓여서
* 의외성 예산·사전 징후·부성향(버릇)은 2단계. 점수 공식 숫자는 지금은 상수, QA 튜닝 시작할 때 데이터로
* 플레이 중 발견: 진지에 적이 남아 있는데 확보 성공이 뜸. 기획 결정은 "적 없이 60초"였는데, 구현이 "싸울 수 있는 적 없이"로 판정해서 붕괴한 적을 없는 것으로 셌음(60초 타이머는 정상). 붕괴한 적도 막도록 수정 — 진지에 적이 남아 있는 한 점령이 아니고, 붕괴한 적은 스스로 물러나므로 영원히 막지 않음

다음 작업
* 계획 명령(feature/plan-orders 제안) — 대기 지점·신호 대기·조건부 출발. 작전의 동시성(포위·망치와 모루·성동격서)을 반사신경이 아니라 계획으로 맞춤. 신호도 통신을 탐. 장비 맵(차량·헬기)일수록 필요 — 이벤트 일시정지보다 먼저
* 2단계: 의외성 예산(판당 0~1회) + 사전 징후 + 부성향(버릇), 브리핑 성향 게이지
* 또는 공격하는 적 / 난이도 손잡이(내다보기·협동·정찰)
* 사건 알림(feature/event-pause): 일시정지 = 지금 결정할 게 있는 사건(첫 접촉 = 새 접촉 번호, 점령 시작) / 경고 문구 = 알아야 하지만 당장 명령할 게 없는 사건(소대 첫 피해, 전투 가능 70%·50% 아래, 붕괴). 경고는 실제 시간 기준으로 표시(배속과 무관), 여러 개면 쌓아서 보여줌. 본부가 아는 사건만(보고 도착 시점). 통신 두절은 일부러 제외 — 아군 소대를 자주 살피는 습관이 재미, 막상 보면 끊겨 있는 상황이 연출되게

QA 때 볼 것
* 성향별 판단 분포(블루 3개 소대가 1진지로 돌파 이동하는 스크립트, 20판): 공격성 0.1 = 고수·증원만, 0.35 = 증원 18·역습 2, 0.9 = 매판 역습. 블루 승리는 성향과 상관없이 0/20(판정 수정 전에는 0.9에서 8/20이었지만, 역습한 예비대가 붕괴한 채 진지에 남아 있는데 확보 판정이 난 판이었음)
* 확보 판정 수정의 영향: 테스트 시나리오 블루 2개 소대 돌파 스크립트 40판 승리 10 → 4. 기존 밸런스 기준선(엄호+우회 40판 중 2판)도 다시 잴 것
* 후퇴는 스크립트 판에서 한 번도 안 나옴(역사면 진지가 피해를 거의 안 입음). 플레이어가 진지를 실제로 몰아붙이면 나오는지
* 증원 가는 예비대가 능선 뒤 개활지를 일반 이동하다 맞아 붕괴하는 경우가 있음
* 진지·후퇴 위치·위협 반경 200m는 임시 값(데모 맵 만들 때 다시)
* 전투 가능 0명인데 붕괴 상태로 남는 소대가 있음(기존 동작, 이번 작업과 무관 — 따로 확인)
* 배속 체감: 1배속은 너무 느리고 20배속이어야 움직이는 맛이 남(1km 이동에 15분 남짓). 배속 단계·이동 속도·점령 시간(60초) 조정 검토

공개용 메모
* "적장은 성격이 있다 — 신중한 적은 예비대를 아끼고, 공격적인 적은 바로 역습한다" — 같은 판을 성향만 바꿔 돌린 비교 감
