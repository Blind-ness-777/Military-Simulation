## 2026-10-26 · 설계 결정: 플레이어 시점

오늘 한 작업
* 플레이어를 상급부대 시점(AI 지휘관에게 맡기고 전장 조망)으로 바꿀지 하루 검토

문제 / 결정 사항
* 플레이어 = 본부 분대 유지 — 소대를 직접 움직이는 맛이 이 게임의 재미. 상급부대 시점은 배치 후 AI가 풀어 가는 걸 보는 오토 배틀러에 가까워짐
* 상급부대 지원은 스킬 형태의 요청으로: 시나리오별 횟수 제한, 요청도 통신을 탐(본부 통신 상태·통신병 영향), 본부 상황판 위치 기준 조준(보고가 늦으면 빗나감), 도착 지연
* 상급부대 시점은 대대급 이상 큰 규모에서 나중에 검토. 지금 만드는 적 지휘관 AI가 그때 아군 하급 지휘관 AI로 재활용될 수 있음
* "전장을 내려다보는 느낌"은 역할이 아니라 연출(작전 테이블 같은 지도, 보고대로 옮겨지는 말)로 살림

다음 작업
* 디버그 가독성 정리 또는 지형 확장·맵 로딩 (한 판 루프 — 목표·승패, 적 AI, 투입 지점, AAR — 를 먼저 할지도 검토)

공개용 메모
* "왜 플레이어는 장군이 아니라 본부 분대인가" — 설계 의도 글감

## 2026-10-25 · feature/report-delay (#7)

오늘 한 작업
* 소대별 인지: 각 소대가 직접 본 적을 따로 기억 — 완료
* 소대 → 본부 보고 채널: 정상 즉시, 저하 15초 지연(위치는 5초 간격), 두절 시 보류 후 회복되면 순서대로 전달
* 아군도 보고 기반 표시: 보고가 끊긴 소대는 마지막 보고 위치에 흐리게, "마지막 보고 07:12 (2분 전)" 표시
* 테스트 6개 추가 (총 38개)

문제 / 결정 사항
* 플레이어 = 본부. 화면은 본부가 아는 것만 보여줌(아군 포함)
* 추정 위치는 표시하지 않음 — 데모 피드백 후 불편하면 추가
* 표적 정보 공유: 통신이 되는 소대는 본부 상황판의 확인된 접촉도 사격, 두절된 소대는 자기가 본 적만
* 본부는 소대의 실제 상태를 모름: 명령 발신 시 전멸·붕괴 검사 안 함, 도착 시 처리
* 저하 상태 화면 차이가 작음(15초 늦은 생중계 같은 느낌) — 값은 그대로 두고 QA 때 조정

다음 작업
* refactor/unit-types

QA 때 볼 것
* 통신 저하 체감: 보고 간격(5초)·보고 지연(15초)
* 발견 보고 도착 전 사격 시작하면 로그가 "사격 개시 → 적"으로 표기됨

공개용 메모
* "통신이 끊긴 소대는 지도에서 마지막 보고 위치에 멈춰 있다. 실제로 어디 있는지는 연락이 닿아야 안다." — 두절 전후 비교 GIF 감
